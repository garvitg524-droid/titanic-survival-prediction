# 🚢 Titanic Survival Prediction Using Machine Learning

## 📌 Project Overview
This project explores the Titanic passenger dataset and builds machine learning models to predict passenger survival.

## 🧰 Libraries Used
- **Pandas:** data manipulation and analysis
- **NumPy:** numerical operations
- **Seaborn:** statistical visualization
- **Matplotlib:** charts and plots

## 🔎 Workflow

### 1. Load Data
Load the training and test CSV datasets using Pandas.

### 2. Exploratory Data Analysis
- Visualize distributions of age, fare, SibSp, and Parch.
- Explore relationships between passenger features and survival.

### 3. Data Cleaning
- Handle missing values.
- Remove columns considered irrelevant to the model.
- Perform feature engineering.

### 4. Model Testing
Evaluate multiple machine learning models, including:
- Decision Tree
- LightGBM
- XGBoost
- Random Forest
- Extra Trees
- Logistic Regression

## 📊 Result
The original project reports **73.8% accuracy** for its selected model.

## 📦 Test Submission
Generate predictions for the test dataset and save them in a submission file.

## ✅ Conclusion
This project demonstrates an end-to-end machine learning workflow on historical passenger data, from exploratory analysis and data preparation to model evaluation and prediction.
